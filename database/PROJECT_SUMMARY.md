## What's Included

### 1. Complete Prisma Schema (schema.prisma)

**10 Models:**
- User (platform users)
- MailerProfile (delivery person profiles)
- Order (card delivery orders)
- CardTemplate (pre-designed cards)
- AddOn (optional gifts)
- OrderAddOn (join table)
- LegacyLetter (future scheduled deliveries)
- Payout (mailer earnings)

**5 Enums:**
- Role (SENDER, MAILER, ADMIN)
- OrderStatus (PENDING → PAID → ASSIGNED → IN_TRANSIT → DELIVERED)
- CardType (BIRTHDAY, CHRISTMAS, THANK_YOU, etc.)
- DeliveryType (STANDARD, RUSH, SCHEDULED)
- PayoutStatus (PENDING, PROCESSING, PAID, FAILED)

**Key Features:**
- Money stored in cents (integers) to avoid rounding errors
- Geolocation fields (lat/lng) for mailer-order matching
- Clerk integration via `clerkId` field
- Comprehensive indexes for performance
- Cascade deletes where appropriate
- Automatic timestamps (createdAt, updatedAt)

## Database Design Highlights

### Money Handling
All prices stored as integers (cents):
```javascript
basePriceCents: 700        // $7.00
deliveryFeeCents: 300      // $3.00
totalPriceCents: 1000      // $10.00
```

### Location-Based Matching
```javascript
// Mailer profile
latitude: 30.2672          // Austin, TX
longitude: -97.7431
radiusMiles: 15

// Order delivery address
latitude: 30.2700
longitude: -97.7450

// Calculate distance and match within radius
```

### Clerk Authentication Integration
```javascript
// User record links to Clerk
{
  id: "uuid",
  clerkId: "clerk_user_abc123",  // From Clerk
  email: "user@example.com",
  firstName: "John",
  role: "SENDER"
}
```

### Order Workflow
```
PENDING (created, not paid)
  ↓
PAID (payment received)
  ↓
ASSIGNED (mailer accepted)
  ↓
PRINTING (card being printed)
  ↓
IN_TRANSIT (mailer delivering)
  ↓
DELIVERED (completed)

(Can also go to CANCELLED or REFUNDED)
```

### Pricing Breakdown
```javascript
{
  basePriceCents: 700,       // Card template
  deliveryFeeCents: 300,     // Delivery fee
  addOnsTotalCents: 1200,    // Chocolates
  totalPriceCents: 2200,     // Customer pays $22.00
  platformFeeCents: 330,     // MailIt keeps $3.30 (15%)
  mailerPayoutCents: 1870    // Mailer gets $18.70
}
```

## Usage Examples

### Basic Queries

```javascript
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();

// Find all active mailers
const mailers = await prisma.mailerProfile.findMany({
  where: { isActive: true },
  include: { user: true }
});

// Get user's orders
const orders = await prisma.order.findMany({
  where: { senderId: userId },
  include: {
    cardTemplate: true,
    addOns: { include: { addOn: true } },
    mailer: { include: { user: true } }
  }
});

// Create new order
const order = await prisma.order.create({
  data: {
    orderNumber: generateOrderNumber(),
    status: 'PENDING',
    senderId: userId,
    cardType: 'BIRTHDAY',
    message: 'Happy Birthday!',
    // ... other fields
  }
});
```

### Next.js Integration

```typescript
// lib/prisma.ts
import { PrismaClient } from '@prisma/client';

const globalForPrisma = global as unknown as { prisma: PrismaClient };

export const prisma =
  globalForPrisma.prisma ||
  new PrismaClient({ log: ['query'] });

if (process.env.NODE_ENV !== 'production')
  globalForPrisma.prisma = prisma;

// app/api/orders/route.ts
import { prisma } from '@/lib/prisma';

export async function GET() {
  const orders = await prisma.order.findMany();
  return Response.json(orders);
}
```

## Key Features

### 1. Type Safety
Prisma generates TypeScript types automatically:
```typescript
// Type-safe queries
const order: Order = await prisma.order.findUnique({
  where: { id: orderId }
});
```

### 2. Relation Loading
```javascript
// Include related data
const order = await prisma.order.findUnique({
  where: { id: orderId },
  include: {
    sender: true,
    mailer: { include: { user: true } },
    cardTemplate: true,
    addOns: { include: { addOn: true } }
  }
});
```

### 3. Aggregations
```javascript
// Calculate mailer earnings
const stats = await prisma.order.aggregate({
  where: {
    mailerId: mailerId,
    status: 'DELIVERED'
  },
  _sum: { mailerPayoutCents: true },
  _count: true
});
```

### 4. Transactions
```javascript
// Atomic operations
const result = await prisma.$transaction([
  prisma.order.update({
    where: { id: orderId },
    data: { status: 'DELIVERED' }
  }),
  prisma.mailerProfile.update({
    where: { id: mailerId },
    data: { completedJobs: { increment: 1 } }
  })
]);
```
